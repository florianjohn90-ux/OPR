# Hintergrundmusik für Listicle-Reels

Lege hier **lizenzfreie** Tracks ab (.mp3/.m4a/.wav) — die Engine rotiert sie
automatisch pro Post. Gute Quellen: YouTube Audio Library, Pixabay Music,
Higgsfield-Soundtracks (sofern Lizenz kommerzielle Nutzung erlaubt).
Stil-Empfehlung: ruhiger Lofi/Chill-Beat, 60-90 BPM, kein Gesang.
Ohne Dateien hier nutzt die Engine einen generierten Ambient-Pad als Fallback.
WICHTIG: Keine kommerziellen Charts-Songs — Copyright-Strike-Gefahr.
